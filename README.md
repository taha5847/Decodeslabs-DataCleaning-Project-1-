# Data Cleaning & Preparation | DecodeLabs Internship – Project 1

## 📌 Project Overview

This project is part of **Project 1: Data Analytics Internship at DecodeLabs (2026)**.

The objective is to clean and prepare a raw dataset by identifying data-quality issues, correcting inconsistencies, and making the data more reliable for further analysis.

Data cleaning is an essential step in the data analytics lifecycle because accurate analysis depends on accurate and consistent data.

## 🎯 Project Objectives

- Standardize date formats.
- Identify and verify missing or null values.
- Handle blank coupon code entries.
- Improve data consistency and reliability.
- Prepare the dataset for future analysis.

## 🛠️ Data Cleaning Tasks

### 1. Date Format Standardization
- Identified the date column in the dataset.
- Changed the date format to maintain consistency.
- Ensured dates follow a standardized format for easier analysis.

### 2. Missing / Null Value Verification
- Checked the dataset for missing and null values.
- Reviewed blank cells across the columns.
- Verified data completeness after the cleaning process.

### 3. Coupon Code Cleaning
- Identified blank cells in the `Coupon Code` column.
- Replaced blank coupon code values with **`No Coupon`**.
- Maintained consistency without leaving coupon entries empty.

**Example:**

| Original Coupon Code | Cleaned Coupon Code |
|---|---|
| SAVE20 | SAVE20 |
| WELCOME10 | WELCOME10 |
| Blank | No Coupon |
| Blank | No Coupon |

## 📊 Key Skills Demonstrated

- Data Cleaning
- Data Preparation

## 🔍 Final Data Quality Checks

The final validation focuses on:

- Consistent date formatting.
- No remaining missing or null values.
- No blank coupon code entries.
- Blank coupon codes represented as `No Coupon`.
